# TravelLog

Одностраничный сайт дневника путешествий TravelLog для Android. Знакомит с приложением, описывает его основные экраны и предлагает скачать APK.

## Содержание

- Краткое описание приложения.
- Записи с фотографиями, отметки мест на карте и объединение записей в поездки.
- Описание ленты, карты, статистики и настроек.
- Локальное хранение дневника и перенос данных через ZIP.
- Скачивание версии 1.0.1 и ответы на частые вопросы.

## Оформление

Визуальная идея – дорожный журнал: тёплый светлый фон, тёмно-бирюзовая типографика, коралловые акценты. Заголовки с засечками сочетаются с простым шрифтом основного текста.

В основе оформления шесть цветов и не более пяти размеров шрифта на каждом диапазоне ширины экрана. Интерфейсные иконки выполнены в SVG; знак приложения адаптирован к палитре сайта. Вёрстка адаптируется к компьютерам, планшетам и телефонам, а эффекты учитывают системную настройку уменьшения движения.

Сайт написан на HTML и CSS без сторонних библиотек. На странице используются скриншоты приложения, предоставленные пользователем 2 ноября 2026 года. Файлы сайта и изображения хранятся локально, внешние шрифты и аналитика не подключены.
