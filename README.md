# TravelLog

Одностраничный сайт дневника путешествий TravelLog для Android. Знакомит с приложением, показывает его основные экраны и предлагает скачать APK.

## Содержание

- Краткое описание приложения.
- Записи с фотографиями, отметки мест на карте и объединение записей в поездки.
- Скриншоты ленты, карты, статистики и настроек с возможностью увеличения.
- Локальное хранение дневника и перенос данных через ZIP.
- Скачивание версии 1.0.1 и ответы на частые вопросы.

## Оформление

Визуальная идея — дорожный журнал: тёплый светлый фон, тёмно-бирюзовая типографика, коралловые акценты и графика маршрута. Заголовки с засечками сочетаются с простым шрифтом основного текста.

В основе оформления шесть цветов и не более пяти размеров шрифта на каждом диапазоне ширины экрана. Иконки выполнены в SVG. Вёрстка адаптируется к компьютерам, планшетам и телефонам, а эффекты учитывают системную настройку уменьшения движения.

Сайт написан на HTML, CSS и JavaScript без сторонних библиотек. Скриншоты взяты из приложения; в них используются тестовые записи. Файлы сайта и изображения хранятся локально, внешние шрифты и аналитика не подключены.
